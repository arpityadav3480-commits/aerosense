Endpoints

Hosted by ThingSpeak. All responses are JSON unless noted.

REQUESTRETURNS
GET/channels/3462136/feeds/last.jsonLatest reading
GET/channels/3462136/feeds.json?results=50Last N readings (max 8000)
GET/channels/3462136/fields/5.json?results=100One field only (here: IAQ)
GET/channels/3462136/feeds.json?start=2026-10-27%2000:00:00Readings since a date (UTC)
GET/channels/3462136/feeds.csv?results=8000Same data as CSV

Base URL: https://api.thingspeak.com

Example

Read the latest values from JavaScript or Python.

// JavaScript const r = await fetch( "https://api.thingspeak.com/channels/3462136/feeds/last.json"); const d = await r.json(); console.log("Temp:", d.field1, "IAQ:", d.field5); # Python import requests d = requests.get( "https://api.thingspeak.com/channels/3462136/feeds/last.json").json() print("Temp:", d["field1"], "IAQ:", d["field5"])
